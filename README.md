# 🏠 Home Tracker

A beautiful, cozy web application to track who's currently home and analyze presence patterns over time. Built with React and TypeScript.

![Home Tracker Preview](https://img.shields.io/badge/React-18+-blue?logo=react) ![TypeScript](https://img.shields.io/badge/TypeScript-5+-blue?logo=typescript) ![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Features

### 🔄 Real-time Tracking
- **Toggle switches** to mark people as home or away
- **Automatic sorting** - people at home appear at the top
- **Live counter** showing how many people are currently home
- **Session-based tracking** starting from zero when the app launches

### 👥 People Management
- **Add new people** with a simple input form
- **Remove people** who no longer live there
- **Visual status indicators** with color-coded dots and backgrounds
- **Time tracking** showing hours spent at home for each person

### 📊 Analytics Dashboard
- **Interactive radar chart** visualizing home presence patterns
- **Statistics cards** showing who's been home the most and average time
- **48-hour perspective** for meaningful insights
- **Real-time data** based on actual toggle history

### 🎨 Beautiful Design
- **Cozy white UI** with soft shadows and rounded corners
- **Smooth animations** for all interactions
- **Mobile-friendly** responsive design
- **Green accent colors** for a warm, homey feel
- **Clean typography** with Inter font
